# 🌐 Personal Portfolio Website

Welcome to the repository of my personal portfolio website. This project serves as a digital resume and a showcase of my skills, full-stack web applications, AI integrations, and professional journey as a developer.

🔗 **Live Demo:** [apratapsingh2027-collab.github.io/Portfolio/](https://apratapsingh2027-collab.github.io/Portfolio/)

---

## 🚀 Features

*   **📱 Fully Responsive Design:** Optimized for all screen sizes including smartphones, tablets, and desktops.
*   **💻 Project Showcase:** Interactive section highlighting my best work, including the MERN-based AI Resume Analyzer.
*   **🛠️ Detailed Skill Matrix:** Visually categorized technical skills (Frontend, Backend, Databases, and AI Tools).
*   **✉️ Contact/Inquiry Form:** A seamless way for recruiters and clients to get in touch with me.
*   **⚡ High Performance:** Clean code architecture ensuring fast loading times and smooth animations.

---

## 🛠️ Built With

*   **HTML5 & CSS3** - For structural semantic layout and styling.
*   **JavaScript (ES6+)** - For dynamic behavior and interactive components.
*   **Tailwind CSS** *(If used, otherwise keep it clean CSS)* - For a modern, utility-first design.
*   **GitHub Pages** - Hosted directly from this repository.
